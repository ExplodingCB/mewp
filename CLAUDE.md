# Mewp

A free, open-source, native Swift/SwiftUI macOS cleaner (formerly CleanMyMewp; renamed
to stay clear of MacPaw's CleanMyMac trademark). No malware detection or app updater. Personal use only; built locally in Xcode
with ad-hoc "Sign to Run Locally" signing (no paid Apple Developer account).

## Build & run

The Xcode project is generated by [XcodeGen](https://github.com/yonabu/XcodeGen) from
`project.yml` — **edit `project.yml`, never the `.xcodeproj` directly**, then regenerate.

```sh
xcodegen generate                                                   # after adding/removing files or editing project.yml
xcodebuild -project Mewp.xcodeproj -scheme Mewp \
  -configuration Debug -destination 'platform=macOS' build          # build
xcodebuild ... test                                                 # run unit tests
open ~/Library/Developer/Xcode/DerivedData/Mewp-*/Build/Products/Debug/Mewp.app
```

Requirements: Xcode 26, macOS 14+ deployment target, Apple Silicon or Intel. Swift 5 language mode
(`SWIFT_VERSION: 5.0`) to keep strict-concurrency friction low.

## Architecture

- `Sources/App/` — `@main` app, `RootView` sidebar navigation, module enum.
- `Sources/Core/`
  - `Scanner/` — `DirectoryScanner` (size measurement), `TreeScanner` (FileNode tree,
    collapses `.app`/`.photoslibrary` packages), `FileWalker` (bounded parallel flat scan).
  - `SafetyRules/` — **the safety database**: `SafetyRules.categories()` is the single
    source of truth for what Cleanup touches; `JunkScanner` expands it into sized items.
  - `Deletion/` — `Deleter`, trash-first with a `permanent` override.
  - `Duplicates/` — `DuplicateFinder` (size → 64KB partial hash → full SHA-256).
  - `Images/` — local dHash prefilter plus Vision feature-print comparison.
  - `Maintenance/`, `StartupItems/`, `System/` — administrator-prompted maintenance,
    launchd controls, diagnostics, and the low-overhead menu-bar sampler.
  - `Uninstaller/` — application inventory and strict bundle-ID leftover matching.
  - `Permissions/` — `FullDiskAccess` probe + deep-link; `PermissionsModel`.
  - `Util/` — `ByteFormat`, `concurrentMap`, `FileActions` (reveal/trash), `VolumeSpace`.
- `Sources/Modules/` — nine modules: Checkup, Cleanup, Space Map, Large Files,
  Duplicates, Uninstaller, Similar Images, Performance, and Startup Items.
- `Tests/MewpTests/` — engine tests against throwaway fixture trees (never the real home dir).

## App icon

The icon is drawn in code by `scripts/make-icon.swift` (a flat white cat head on a blue
tile). Edit the script and rerun `swift scripts/make-icon.swift` rather than replacing the
PNGs by hand. It also rewrites `app-icon.png`, which the similar-images test uses as a fixture.

## README screenshots

Debug builds can capture their own window (via ScreenCaptureKit, no Screen Recording
permission needed). Regenerate `docs/screenshots/` with:

```sh
APP=build/Build/Products/Debug/Mewp.app/Contents/MacOS/Mewp
MEWP_MODULE="Space Map" MEWP_SPACEMAP_ROOT=/System/Library MEWP_SNAPSHOT_DELAY=20 \
  MEWP_APPEARANCE=dark MEWP_SNAPSHOT=/tmp/space-map.png $APP
MEWP_MODULE=Checkup MEWP_APPEARANCE=dark MEWP_SNAPSHOT=/tmp/checkup.png $APP
MEWP_MODULE=Performance MEWP_APPEARANCE=dark MEWP_SNAPSHOT_DELAY=6 MEWP_SNAPSHOT=/tmp/performance.png $APP
sips -Z 1600 /tmp/space-map.png --out docs/screenshots/space-map.png   # and so on
```

Only screenshot screens without personal data: never a scanned home folder, the Uninstaller's
app list, Large Files, or Duplicates results.

## Keep clear of MacPaw's IP

Mewp is an independent, open-source cleaner. Don't use MacPaw's product or feature names
anywhere in the UI, code, identifiers, or docs: CleanMyMac, Smart Care, Space Lens, Large & Old
Files, My Clutter, Moonlock, and so on. Pick plain descriptive names instead (Checkup, Space
Map, Large Files). The only allowed mention is the trademark notice at the end of the README.
Never copy MacPaw artwork, icons, sounds, or marketing text, and don't describe a design as
imitating theirs in comments.

## Non-negotiable safety rules

- **Trash-first.** Default deletes go to Trash via `FileManager.trashItem`; permanent unlink
  is opt-in. `~/.Trash` contents are the one exception (can't trash the Trash).
- Everything removable is defined in `SafetyRules` with a `RiskLevel`; only `.safe` is
  pre-selected. Forbidden roots (`/System`, `/private/var/folders`, `.lproj`/lipo stripping)
  are excluded by design — see `SafetyRules.excludedByDesign` and the `testNoCategoryTargetsForbiddenRoots` test.
- Never modify app bundles (breaks code signatures/notarization).

## Gotchas learned the hard way

- **Never do blocking work in a view-model initializer.** `PerformanceViewModel` used to call
  `PerformanceSnapshot.current()` from its `init`, which SwiftUI runs *inside* a view-graph
  update. The old `SystemCommand.run` used `Process.waitUntilExit()`, which **runs the current
  run loop** — re-entering SwiftUI's run-loop observer mid-update and tripping an AttributeGraph
  reentrancy precondition (`abort()`). `SystemCommand` now waits on a semaphore signalled from
  `terminationHandler` and asserts it is off the main thread.
- **Prefer sysctl/mach over subprocesses on any polling path.** Memory pressure
  (`kern.memorystatus_vm_pressure_level`), swap (`vm.swapusage`), and Low Power Mode
  (`ProcessInfo.isLowPowerModeEnabled`) are all native. Only the top-process table still shells
  out to `ps -A`, and it runs on every third poll.
- **Liquid Glass is macOS 26+.** Space Map bubbles use `GlassEffectContainer` /
  `glassEffect(_:in:)` / `glassEffectID` behind `if #available(macOS 26.0, *)`, falling back to
  the shaded-sphere rendering so the macOS 14 target still builds and runs.
- **The Space Map tree was the memory hog, not the pollers.** `TreeScanner` allocated a
  `FileNode` per filesystem entry and `SpaceMapViewModel` held the whole tree. Measured
  against the real home directory: **1,811,788 nodes → 24,005** after capping kept file leaves
  at 40 per directory (was 500 — so high the aggregation almost never fired) and stopping tree
  construction at depth 5, where directories are measured and marked `isUnexpanded` and filled
  in on drill. If sizes ever look wrong, check that a deferred node's `size` came from
  `DirectoryScanner.measure`, not from summing absent children.
- Whole-home scans are inherently syscall-heavy — every entry must be stat'd to size it. Node
  count is the lever; the traversal itself is not.
- **Ambient animation is the expensive kind.** Always-on effects (drifting full-window
  gradients, blurred rotating layers) re-rasterise every frame. Motion belongs on transitions,
  interactions, and hover — see the `Motion` vocabulary in `Theme.swift`.
- **`xcodebuild test` leaves a stale `MewpTests.xctest` inside the Debug `.app`**, which
  makes the next `build` fail codesign with "bundle format unrecognized". Delete the Debug
  `Mewp.app` before rebuilding.
- **Do not force-resize the window via AppleScript.** Doing so persisted a bogus
  `NSSplitView Subview Frames` height into the app's defaults, which restored a split view
  taller than the window and pushed all content off the top on every launch. Recover with
  `defaults delete com.chaseculbertson.Mewp` plus removing its `Saved Application State`.
- Replacing `/Applications/Mewp.app` invalidates its Full Disk Access grant, because an
  ad hoc signature is tied to the bundle's cdhash. Re-grant after every install.

## Releasing

The app ships two places: a GitHub release on `ExplodingCB/mewp` and a Homebrew cask in
`ExplodingCB/homebrew-tap` (`brew install --cask explodingcb/tap/mewp`).

```sh
xcodegen generate
xcodebuild -project Mewp.xcodeproj -scheme Mewp -configuration Release \
  -destination 'platform=macOS' -derivedDataPath ./build \
  ARCHS="arm64 x86_64" ONLY_ACTIVE_ARCH=NO build          # universal, both arches
ditto -c -k --sequesterRsrc --keepParent \
  build/Build/Products/Release/Mewp.app dist/Mewp-<version>.zip
shasum -a 256 dist/Mewp-<version>.zip              # goes in the cask
gh release create v<version> dist/Mewp-<version>.zip --repo ExplodingCB/mewp
```

Then bump `version` and `sha256` in the tap's `Casks/mewp.rb` and push. The cask has a
`postflight` that runs `xattr -dr com.apple.quarantine`, because the ad hoc signature is not
notarized and macOS would otherwise refuse to open the downloaded bundle.

Check the cask with `brew style --cask Casks/mewp.rb` and
`brew audit --cask --strict --online explodingcb/tap/mewp` — both pass clean, so treat a
new offense as a real regression. Do **not** use `brew audit --cask --new`: those are the rules
for submitting to homebrew-cask core, and two of them can never pass here — "repository not
notable enough" (needs 75+ stars) and Gatekeeper signature verification (needs a Developer ID
certificate and notarization, i.e. a paid Apple Developer account). Lint history: `depends_on
macos: ">= :sonoma"` and `url ..., verified:` are deprecated spellings, and `desc` may not name
the platform.

## Status

Version 0.4.1 (build 7) cuts Space Map memory by ~75× (1.81M tree nodes → 24k on a real home
directory) via a 40-file-per-directory leaf cap and depth-5 lazy expansion, and drops the two
unread `Date?` fields from every node. 32 unit tests pass.

Version 0.4.0 (build 6) fixed the AttributeGraph crash that made the Performance module
abort on open, cuts idle resource use (four subprocesses every 5 s → one every 3 min; menu-bar
sampler 2 s → 3 s while its popover is open and 5 min otherwise; Trash measurement every 10 min
instead of every minute), gives Checkup an app-leftovers pass, and adds a motion vocabulary
plus Liquid Glass Space Map bubbles on macOS 26.

Phases 1 through 5 and the roadmap gap pass are complete since version 0.3.0. The app has
nine modules plus a menu-bar monitor, and 31 unit tests pass. Cleanup now includes
reviewed browser, sandbox-container, package-manager, removable-volume Trash, and
root-owned `/Library` entries. Checkup includes system-health recommendations and
the menu-bar shortcut can start its scan. Uninstaller includes six-month unused-app
filtering, signing metadata, expanded reviewed matches, and conservative orphaned
bundle-ID detection. Large-file and duplicate walks use bounded top-level concurrency.
A persistent privileged helper was replaced
with macOS per-action administrator prompts because an ad hoc shared build cannot
securely authenticate helper callers. Broad root-cache deletion is intentionally absent;
the cleaner only removes individually reviewed `/Library` children from the safety
database and moves them to Trash. Full plan:
`~/.claude/plans/so-theres-an-app-vivid-iverson.md`.
